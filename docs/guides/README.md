## Guide Format

Each guide follows a consistent structure:

1. **Prerequisites** - What you need before starting
2. **Step-by-step Instructions** - Detailed walkthrough
3. **Verification** - How to confirm it's working
4. **Common Issues** - Quick fixes for frequent problems
5. **Next Steps** - What to do after completion

## Contributing Guides

When creating new guides:

1. Focus on a single workflow or task
2. Include real command examples
3. Add screenshots or code blocks where helpful
4. Test all steps before publishing
5. Link to related documentation
6. Keep language clear and concise
