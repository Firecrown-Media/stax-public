## Instructions
When automating tests:
1. Use Go's built-in testing package
2. Organize tests alongside source code (*_test.go)
3. Use testify/assert for clear assertions
4. Create test helpers for common operations
5. Use testify/mock for mocking
6. Implement table-driven tests
7. Run tests in parallel where safe (t.Parallel())
8. Use test fixtures for setup/teardown
9. Generate code coverage reports
10. Integrate with CI/CD
11. Keep tests fast and independent
12. Use build tags for integration tests
13. Document test requirements
14. Maintain test code quality
