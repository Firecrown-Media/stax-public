## Instructions
When testing security:
1. Test with malicious inputs (SQLi, XSS, command injection)
2. Attempt path traversal with ../ patterns
3. Test authentication and authorization
4. Verify encryption and secure communications
5. Test rate limiting and DoS protections
6. Check for information disclosure
7. Verify input validation on all endpoints
8. Test with edge cases and boundary values
9. Check for insecure defaults
10. Verify credential storage security
11. Test error handling for information leakage
12. Document all findings with severity ratings
13. Provide proof of concept exploits
14. Suggest remediation for vulnerabilities
