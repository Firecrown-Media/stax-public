## Instructions
When building Go applications:
1. Use Cobra for CLI structure and commands
2. Implement proper error handling with context
3. Use Viper for configuration file management
4. Leverage cobra-cli for scaffolding
5. Write tests for all critical functionality
6. Handle cross-platform paths correctly
7. Use build tags for platform-specific code
8. Optimize for fast compilation
9. Follow Go project layout conventions
10. Create releases with goreleaser for multiple platforms
