## Instructions
When creating documentation:
1. Write for the intended audience level (junior devs)
2. Use clear, simple language - avoid jargon
3. Include lots of concrete examples
4. Show expected output for commands
5. Explain WHY, not just WHAT
6. Provide troubleshooting for common issues
7. Use proper markdown formatting
8. Structure docs logically (overview → details)
9. Include both quick start and deep dives
10. Test all examples and commands
11. Use consistent terminology throughout
12. Add links to related concepts
