- Infrastructure security hardening
- Deployment security best practices
- Access control and authentication

- Certificate management

## Instructions
When implementing security:
1. Apply defense in depth principles
2. Follow principle of least privilege
3. Implement secure defaults
4. Use encryption in transit and at rest
5. Validate all inputs and outputs
6. Enable comprehensive logging
7. Implement rate limiting where appropriate
8. Use security headers and configurations
9. Regular security patching and updates
10. Document security controls
11. Test security implementations
12. Plan for incident response
